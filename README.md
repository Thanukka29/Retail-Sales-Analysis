# Retail Sales Analysis Dashboard

## Project Overview
This project focuses on analyzing retail sales data using Microsoft Excel and Power BI. The goal is to understand sales performance, profitability, customer activity, product performance, and regional sales trends through an interactive dashboard.

## Tools Used
- **Microsoft Excel** – Dataset preparation and data handling
- **Microsoft Power BI** – Data visualization and interactive dashboard creation

## Dataset Details
The dataset contains 150 retail sales records from January to September 2026.

The dataset includes:
- Order ID
- Order Date
- Customer ID
- Product
- Category
- Region
- Sales Channel
- Quantity
- Unit Price
- Sales
- Cost

## Dashboard Features
The Power BI dashboard includes:

- Total Sales
- Total Profit
- Total Orders
- Average Sales
- Profit Margin
- Sales by Category
- Sales by Product
- Sales by Region
- Sales by Sales Channel
- Quantity by Category
- Profit by Category
- Monthly Sales Trend

## Interactive Filters
- Region
- Category
- Sales Channel

These filters help users explore sales performance from different perspectives.

## Key Objectives
- Analyze overall retail sales performance.
- Identify top-performing products and categories.
- Compare sales across different regions.
- Understand Online and Store sales performance.
- Track monthly sales trends.
- Evaluate business profitability.

## Files Included
- `Retail_Sales_Analysis.xlsx` – Retail sales dataset
- `Retail_Sales_Dashboard.pbix` – Interactive Power BI dashboard
- `Dashboard_Screenshot.png` – Dashboard preview

## Conclusion
This project demonstrates practical skills in Excel data handling, Power BI dashboard development, data visualization, and business data analysis. It helps convert raw retail sales data into meaningful business insights.
